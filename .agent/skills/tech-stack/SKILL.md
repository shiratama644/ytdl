## 開発共通のベストプラクティス

### 1. 依存関係の管理
- パッケージ追加時は、不要に依存を増やさない（最小限に保つ）。
- ロックファイル（`bun.lock`, `package-lock.json`, `poetry.lock` 等）を必ずコミット対象に含める。

### 2. 環境差分の防止
- 相対パスインポートやエイリアス設定を統一する。
- OS固有のパスセパレータ等に依存しないコードを書く。

### 3. API を記憶で書かない
- ライブラリの API は最新の公式ドキュメントを検索・確認する（AGENTS.md §7.5）。存在しないメソッドを発明しない。
