# プロダクト定義 — YouTube Proxy (ytdl)

> 仕様の正本。プロダクトの目的、ターゲット、ユースケース、要件を定義する。

## 1. 概要
- **プロダクト名**: ytdl (YouTube Proxy Web Client & API)
- **ステータス**: フェーズ 1 設計・実装中

## 2. 目的・背景
- 広告・追跡を排した軽量な YouTube 閲覧環境の提供。
- 低スペックサーバーでも軽快に動作するプロキシアーキテクチャの実現。
- Next.js のような高負荷フレームワークを避け、Vite + React (SPA) + 超軽量 Node.js サーバー (Hono) を組み合わせることで、最小限のリソース消費で快適な検索・動画視聴体験を提供する。

## 3. 主要ターゲット / ユーザー像
- 軽量かつ高速に YouTube 動画を検索・視聴したいユーザー。
- 制限環境や低スペックサーバー上でセルフホストしたいユーザー。

## 4. ユースケース / 機能要件

### 4.1 コア機能
1. **動画検索 (Search)**
   - キーワードによる動画検索。
   - 検索結果の一覧表示（サムネイル、タイトル、チャンネル名、再生回数、公開日時、動画時間）。
   - 検索サジェストの提供（入力補助）。

2. **ホーム / トレンド・おすすめ (Home / Trending)**
   - 初期画面でのトレンド動画またはおすすめフィードの表示。

3. **動画視聴 (Watch & Player)**
   - YouTube風のモダンなプレイヤー画面。
   - プロキシ経由でのシームレスなストリーミング再生（シーク・Range request対応）。
   - 画質選択（自動 / 360p / 720p / 1080p等）、再生速度変更、フルスクリーン。
   - 動画詳細情報（タイトル、概要欄、チャンネル情報、高評価数等）の表示。

4. **関連動画 (Related Videos)**
   - 視聴画面右側/下部に関連動画リストを表示し、連続視聴が可能。

5. **音声専用モード / バックグラウンド再生支援**
   - 音声ストリームのみの軽量再生モード。

6. **ダウンロード機能**
   - プロキシサーバーを介した動画/音声ファイルのダウンロード支援。

## 5. 非機能要件
- **軽量性**: メモリ・CPU消費を極小化。
- **セキュリティ**: 任意の外部URLへのオープンプロキシ化を防止（YouTubeドメイン・videoIdに限定）。
- **ストリーミング性能**: チャンク単位のストリーミング中継と適切な Content-Range / 206 Partial Content レスポンス。
- **レスポンシブデザイン**: PC / タブレット / スマートフォンの全画面サイズに対応（ダークモード基調）。
